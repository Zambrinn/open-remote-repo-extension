# Open GitHub Remote

Open the GitHub `origin` remote for the current repository in your browser.

## Run

- `npm install`
- Press `F5` to launch the Extension Development Host.
- Open the Command Palette and run: `Open GitHub Origin Remote`
- Or click the status bar button: "$(repo) Open Remote"

## Base Path

Some environments need an extra path segment between `github.com` and `owner/repo`.
Set it via the status bar button or Command Palette:

- Command Palette: `Set GitHub Base Path`
- Status bar: "$(settings-gear) Set Base Path"
- Example value: `copilot-corp`
